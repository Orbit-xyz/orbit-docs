The Merchant API is the off-chain side of Orbit. The contract enforces the money movement. The API keeps the records that a dashboard, checkout and keeper need.

## Base URL

The API is self-hosted from the monorepo:

```bash
cd Orbit/apps/backend
cp .env.example .env     # add Supabase URL and service-role key
npm install
node index.js            # http://localhost:3001
```

| Variable | Purpose |
|---|---|
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | Database (schema in `apps/backend/schema.sql`) |
| `ORBIT_CONTRACT_ID` | Contract to invoke |
| `SOROBAN_RPC_URL` | Soroban RPC endpoint |
| `STELLAR_NETWORK_PASSPHRASE` | Network the transactions are signed for |

## Conventions

- JSON in and out. Send `Content-Type: application/json`.
- IDs are UUIDs. Wallets are Stellar strkeys.
- `usdc_amount` is an **integer in raw units** (7 decimals), the same value the contract uses.
- Timestamps are ISO 8601 UTC.
- Errors have the shape `{ "error": "message" }`. See [Errors](/api-reference/errors).

## Authentication

<Warning>
  The MVP API has no API keys yet. Run it on a private network or behind your own auth proxy. Scoped secret keys are on the [roadmap](/roadmap).
</Warning>

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `POST` | [`/plans`](/api-reference/create-plan) | Create a plan |
| `GET` | [`/plans/{id}`](/api-reference/get-plan) | Retrieve a plan for checkout |
| `POST` | [`/subscriptions`](/api-reference/create-subscription) | Record a subscription after the on-chain handshake |
| `GET` | [`/subscribers`](/api-reference/list-subscribers) | List a merchant's subscribers |
| `POST` | [`/trigger-pull`](/api-reference/trigger-pull) | Sign and submit `pull_funds` |
