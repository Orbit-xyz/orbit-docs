---
title: "List subscribers"
description: "GET /subscribers lists subscriptions across every plan a merchant owns."
---

<Endpoint method="GET" path="/subscribers?merchant_id={merchant_id}" />

## Query

<ParamField query="merchant_id" type="uuid" required>
  Merchant whose subscribers to list.
</ParamField>

## Request

```bash
curl "http://localhost:3001/subscribers?merchant_id=3f0c6a1e-..."
```

## Response `200`

```json
{
  "subscribers": [
    {
      "id": "b2a9e4c1-...",
      "customer_wallet_address": "GDQP...4N2",
      "status": "active",
      "next_billing_date": "2026-10-25T10:00:00Z",
      "plans": { "merchant_id": "3f0c6a1e-...", "name": "Pro Monthly", "usdc_amount": 290000000 }
    }
  ]
}
```
